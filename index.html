Privacy Policy

Last Updated: August 24, 2026

1. Information We Collect

Inspectly does not collect or store personal information. The extension does not require users to create an account or provide their name, email address, phone number, or other personal information.

2. Website Content

Inspectly temporarily accesses information from the webpage when the user explicitly activates the Inspect Element feature.

This information is used only to:

  • Detect the selected webpage element
  • Highlight the selected element
  • Read computed CSS properties
  • Display UI information
  • Generate CSS for copying

The inspected webpage information is processed locally in the user's browser. Inspectly does not send inspected webpage content to a remote server.

3. Data Storage

Inspectly does not maintain a database or cloud storage for inspected webpage information.

Inspectly does not permanently store:

  • Webpage content
  • HTML
  • CSS
  • Browsing history
  • Selected elements
  • Passwords
  • Cookies

4. Analytics and Tracking

Inspectly does not use analytics or tracking services.

Inspectly does not track browsing history, mouse movements, keystrokes, user activity, or website visits.

5. Third-Party Services

Inspectly does not send user data to third-party services. The extension does not use external APIs, advertising networks, analytics services, or data brokers.

6. Permissions

activeTab

Used to temporarily access the currently active webpage after the user explicitly activates Inspectly.

scripting

Used to inject Inspectly's locally bundled inspection code into the active webpage so the extension can inspect and highlight webpage elements.

7. Security

Inspectly processes inspection information locally within the user's browser and does not transmit inspected webpage content to external servers.

8. Children's Privacy

Inspectly is a developer utility and is not specifically directed toward children.

9. Changes to This Privacy Policy

We may update this Privacy Policy when Inspectly's functionality changes. Any changes will be published on this page.
